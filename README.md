# Octano Sistemas

ERP para postos de combustível — plataforma multi-empresa por assinatura.

## Planos
- Básico: 1 empresa — R$99/mês
- Pro: até 3 empresas — R$199/mês
- Rede: ilimitado — R$399/mês

## Stack
- Frontend: HTML/CSS/JS puro
- Backend: Supabase (auth + banco)
- Deploy: Railway

## Setup
1. Configure `js/config.js` com sua SUPABASE_ANON_KEY
2. Execute `octano.sql` no Supabase SQL Editor
3. Deploy no Railway a partir deste repositório
